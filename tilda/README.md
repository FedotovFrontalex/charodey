# Вставка лендинга в Tilda

Готовый код лежит в этой папке, картинки подменены на CDN Tilda (`static.tildacdn.com`,
тот же аккаунт, что у текущего сайта) — **ничего загружать не нужно**.

## Файлы

| Файл | Что это | Объём |
|---|---|---|
| `embed.html` | весь лендинг одним фрагментом | 86 KB — скорее всего НЕ влезет в один блок |
| `part1-styles.html` | шрифт + все стили | 28 KB |
| `part2-content.html` | вся разметка + скрипты | 58 KB |
| `preview.html` | автономная страница для локальной проверки | — |

Блок «HTML-код» (T123) в Tilda имеет лимит ~65 000 символов, поэтому вставляйте **двумя блоками**.

## Пошагово

1. Откройте проект в Tilda → **Создать страницу** (пустую, без блоков) или используйте черновик.
2. Нажмите **+ Блок** → раздел **«Другое»** → блок **T123 «HTML-код»** (Insert HTML code).
3. Откройте `part1-styles.html`, скопируйте **всё** содержимое и вставьте в блок. Сохранить → Закрыть.
4. Снова **+ Блок** → **T123 «HTML-код»** → вставьте **всё** содержимое `part2-content.html`.
   Он должен оказаться **ниже** первого блока. Сохранить.
5. **Настройки страницы →** отключите типовые шапку/подвал Tilda (если добавлены) —
   лендинг уже содержит собственные. Опубликуйте страницу: **Публиковать**.

## После публикации — проверить и донастроить

- **Формы** сейчас показывают экран «Заявка отправлена» без отправки (демо-режим).
  Варианты подключения: заменить `<form data-form>` на штатную форму Tilda (блок Forms)
  или дописать в скрипт отправку в CRM/на почту (в коде есть пометка `TODO: fetch(...)`).
- **Ссылка на политику конфиденциальности** сейчас ведёт на
  `https://fedotovfrontalex.github.io/charodey/privacy.html` — замените в двух местах
  (форма в CTA-баннере и модальное окно) на страницу политики вашего сайта, когда она будет.
- **Метрика/аналитика** — подключается штатно в настройках проекта Tilda.

## Как обновлять

Правки вносятся в `index.html` в корне репозитория (источник правды), затем:

```bash
node .github/scripts/make-tilda-embed.mjs   # пересобрать файлы в tilda/
bash .github/scripts/update.sh "update: описание правки"
```

и содержимое `part1/part2` заново вставляется в блоки Tilda (Ctrl+A → вставить поверх).
